# СтальЭнергоМонтаж — демонстрационный сайт

Статический одностраничный сайт компании «СтальЭнергоМонтаж», опубликованный через GitHub Pages.

## Быстрый старт

Откройте `index.html` в браузере или запустите локальный HTTP-сервер:

```bash
python3 -m http.server 8000
```

После запуска сайт будет доступен по адресу `http://localhost:8000/`.

## Навигация по репозиторию

- `index.html` — главная страница и точка публикации GitHub Pages.
- `src/` — стили и клиентские скрипты.
- `public/` — изображения и другие публичные материалы.
- `legal/` — юридические страницы сайта.
- `docs/` — документация проекта.
- `tests/` — автоматические проверки.
- `scripts/` — служебные команды.

Подробная схема приведена в [`docs/PROJECT_STRUCTURE.md`](docs/PROJECT_STRUCTURE.md).
