# Инструкции для AI-агентов

1. Перед работой получить актуальную ветку `main` и проверить чистоту рабочей копии.
2. Не изменять тексты, дизайн, реквизиты и поведение сайта без прямого поручения владельца.
3. Не добавлять секреты, токены, пароли и персональные данные в Git.
4. Сохранять `index.html` в корне: это точка публикации GitHub Pages.
5. После изменений запускать `./scripts/test.sh` и проверять сайт локально.
6. Обновлять `PROJECT_STATUS.md`, `CHANGELOG.md` и документацию, если изменение влияет на них.
7. Не коммитить временные файлы, локальные настройки и результаты тестов.

## Контроль при переносе на постоянный хостинг

По поручению владельца после переезда обязательно актуализировать адрес сайта и фактические сведения об обработке данных в политике конфиденциальности. Выполнить список в `docs/DEPLOYMENT.md` и отметить результат в `PROJECT_STATUS.md`; не считать перенос завершённым, пока в политике остаётся временный адрес GitHub Pages как действующий адрес сайта.
