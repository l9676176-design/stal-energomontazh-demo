# Состояние проекта

## Текущий статус

- Сайт опубликован через GitHub Pages.
- Главная страница, стили и интерактивные элементы подключены.
- Политика конфиденциальности и согласие на обработку персональных данных размещены отдельными страницами.
- По прямому утверждению владельца опубликована редакция политики от 24 октября 2026 года на основе предоставленного текста АМУР.ИНФО; служебные пометки и лист согласования исключены из публичной страницы.
- Опубликован утверждённый вариант политики без Telegram в полях обращения и без автоматической пересылки заявок в мессенджеры.
- Отдельное согласие и работа демонстрационной формы этим изменением не затрагивались.
- Структура репозитория приведена к единому стандарту проектов.
- Автоматическая проверка структуры и локальных ссылок подключена.

## Не относится к текущей структурной задаче

- Изменение текстов, дизайна и состава разделов сайта.
- Подключение рабочей отправки формы.
- Изменение утверждённых юридических документов.

## Обязательные действия до окончательного запуска

- [ ] После переезда с GitHub Pages заменить временный адрес сайта в политике и сверить сведения о размещении и обработке данных. Список: `docs/DEPLOYMENT.md`.
- [ ] Перед включением реальной отправки согласовать форму, контактный блок и отдельное согласие с утверждённой схемой «телефон / электронная почта / форма»; сейчас на главной ещё остаются прежние обозначения Telegram.
