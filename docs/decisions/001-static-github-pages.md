# Решение 001: сохранить публикацию из корня репозитория

## Решение

Оставить `index.html`, `.nojekyll` и `robots.txt` в корне репозитория.

## Причина

Проект уже опубликован через GitHub Pages из ветки `main`. Сохранение точки входа уменьшает риск изменения адреса или нарушения публикации при структурной реорганизации.
