# Тестирование

Основная команда:

```bash
./scripts/test.sh
```

Проверка подтверждает:

- наличие обязательных папок и служебных файлов;
- наличие главной страницы, стилей, скрипта и изображений;
- работоспособность локальных ссылок `href` и `src` в HTML-файлах.

GitHub повторяет эту проверку автоматически после каждого изменения ветки.
