# Безопасность

- Секреты, токены, пароли и настоящие файлы `.env` запрещено хранить в репозитории.
- Персональные данные посетителей не должны записываться в статические файлы или GitHub.
- При подключении рабочей формы необходимо отдельно определить сервер, хранение данных, контроль доступа и сроки удаления.
- Юридические документы изменяются только после согласования с владельцем и заказчиком.
