# Структура проекта

```text
stal-energomontazh-demo/
├── .github/workflows/   автоматические проверки GitHub
├── config/              пояснения по настройкам окружения
├── docs/                документация и архитектурные решения
├── legal/               юридические HTML-страницы
├── public/images/       изображения сайта и архив согласования
├── scripts/             команды проверки и обслуживания
├── src/scripts/         клиентский JavaScript
├── src/styles/          таблицы стилей
├── tests/smoke/         быстрые проверки структуры и ссылок
├── index.html           главная страница GitHub Pages
├── *-policy/consent     совместимые переходы со старых адресов
├── AGENTS.md            правила для AI-агентов
├── README.md            входная точка документации
├── PROJECT_STATUS.md    текущее состояние
├── CHANGELOG.md         история заметных изменений
└── ROADMAP.md           согласованный план развития
```

`index.html`, `.nojekyll` и `robots.txt` остаются в корне из-за текущей схемы публикации через GitHub Pages.
Корневые страницы политики и согласия сохранены как переходы, чтобы ранее выданные ссылки продолжали работать.
