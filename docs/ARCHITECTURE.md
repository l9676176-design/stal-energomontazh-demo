# Архитектура

Проект является статическим сайтом без серверной части и базы данных.

```text
Браузер
├── index.html
├── src/styles/styles.css
├── src/scripts/script.js
├── public/images/site/
└── legal/*.html
```

GitHub Pages выдаёт файлы непосредственно из ветки `main`. Форма на текущем этапе работает только на стороне браузера и не передаёт сведения во внешнюю систему.
