# Публикация

Рабочая версия публикуется GitHub Pages из основной ветки `main`.

Порядок безопасного обновления:

1. Получить актуальную `main`.
2. Внести согласованные изменения.
3. Запустить `./scripts/test.sh`.
4. Проверить сайт локально.
5. Создать понятный коммит и отправить его в GitHub.
6. После публикации проверить главную и юридические страницы.

## Обязательно при переносе с GitHub Pages на постоянный хостинг

- [ ] Заменить временный адрес `https://l9676176-design.github.io/stal-energomontazh-demo/` в `legal/privacy-policy.html` на фактический адрес рабочего сайта. Старый адрес не оставлять как актуальный адрес СЭМ.
- [ ] Сверить с выбранным размещением сведения о хостинге, месте основных баз и резервных копий, маршруте заявок и обработчиках. Обновить политику и отдельное согласие там, где изменились факты.
- [ ] Проверить открытие новой политики и согласия по постоянному адресу и переходы к ним с формы и главной страницы. Проверить необходимость актуализации сведений, направленных Роскомнадзору.
- [ ] Зафиксировать новый адрес и результат проверки в `PROJECT_STATUS.md`. До выполнения этого списка перенос не считать полностью завершённым.
